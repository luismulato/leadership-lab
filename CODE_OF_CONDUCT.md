# Código de conducta

Este proyecto adopta el espíritu del [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Nuestro compromiso
Queremos una comunidad abierta y respetuosa. Participar en este proyecto debe ser una experiencia libre de acoso para todas las personas, sin importar edad, cuerpo, discapacidad, etnia, identidad de género, nivel de experiencia, nacionalidad, apariencia, religión u orientación sexual.

## Comportamiento esperado
- Usar un lenguaje amable e inclusivo.
- Respetar puntos de vista y experiencias distintas.
- Aceptar con gracia las críticas constructivas y darlas con cuidado.
- Enfocarse en lo que es mejor para la comunidad.

## Comportamiento inaceptable
- Comentarios agresivos, insultos o ataques personales.
- Acoso público o privado.
- Publicar información privada de otras personas sin su permiso.

## Aplicación
Las personas responsables del proyecto pueden editar o eliminar comentarios, commits o issues que incumplan este código, y vetar temporal o permanentemente a quien lo incumpla. Los reportes se envían de forma privada al responsable del proyecto y se tratan con confidencialidad.
